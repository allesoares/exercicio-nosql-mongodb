# Módulo 24 — MongoDB

Consultas MongoDB com uma base fictícia de estudantes e professores.

**Objetivo do exercício:** Neste exercício, você irá praticar consultas no MongoDB utilizando uma base simples de estudantes e professores.

O objetivo é reforçar o uso dos principais comandos de consulta do MongoDB, trabalhando com filtros, ordenações, operadores e campos que podem conter valores simples ou listas.

As consultas estão em `consultas.txt` e os resultados completos em `consultas-e-resultados.txt`. Os dados estão em `estudantes.json` e `professores.json`.
